### ソフトウェア開発：API 管理 / Software Development - API Management

**[`^ 目次に戻る ^`](../README.ja.md#目次)**

[API 管理](https://en.wikipedia.org/wiki/API_management)とは、[アプリケーションプログラミングインターフェース（API）](https://en.wikipedia.org/wiki/API)を作成・公開し、利用ポリシーの適用、アクセス制御、利用者コミュニティの育成、利用統計の収集・分析、パフォーマンスの報告を行うプロセス。

- [Aastro](https://voidrunner3074.github.io/aastro-docs) - Go 製の拡張可能な API ゲートウェイ。 ([ソースコード](https://github.com/voidrunner3074/aastro)) `Apache-2.0` `Go/Docker`

- [Graphweaver](https://graphweaver.com/) - 複数のデータソースを単一の GraphQL API に統合。 ([ソースコード](https://github.com/exogee-technology/graphweaver)) `MIT` `Nodejs`
- [Hasura](https://hasura.io) - Postgres 上に高速なリアルタイム GraphQL API を即座に構築。きめ細かなアクセス制御に対応し、データベースイベントで Webhook を起動することも可能。 ([ソースコード](https://github.com/hasura/graphql-engine)) `Apache-2.0` `Haskell/Docker/K8S`
- [Hoppscotch Community Edition](https://hoppscotch.io) - 高速で美しい API リクエストビルダー。 ([ソースコード](https://github.com/hoppscotch/hoppscotch)) `MIT` `Nodejs/Docker`
- [Kong](https://konghq.com/kong/) - マイクロサービス向け API ゲートウェイ兼プラットフォーム。 ([ソースコード](https://github.com/Kong/kong)) `Apache-2.0` `Lua/Docker/K8S/deb`
- [Lura](https://luraproject.org/) - 高性能な API ゲートウェイ。 ([ソースコード](https://github.com/luraproject/lura)) `Apache-2.0` `Go`
- [Opik](https://www.comet.com/site/products/opik/) `⚠` - 開発から本番までのライフサイクル全体で言語モデルの出力を調整するオブザーバビリティツール群により、LLM アプリケーションの評価・テスト・リリースを支援。 ([ソースコード](https://github.com/comet-ml/opik)) `Apache-2.0` `Docker/Python`
- [Para](https://paraio.org) - オブジェクト永続化、API 開発、認証のための柔軟でモジュール式のバックエンドフレームワーク／サーバー。 ([ソースコード](https://github.com/erudika/para)) `Apache-2.0` `Java/Docker`
- [Svix](https://svix.com) - API 提供者が Webhook を簡単に送信できる Webhook as a Service。 ([ソースコード](https://github.com/svix/svix-webhooks)) `MIT` `Docker/Rust`
- [Tyk](https://tyk.io) - 高速でスケーラブルなオープンソースの API ゲートウェイ。API ゲートウェイ、API 分析、開発者ポータル、API 管理ダッシュボードを備えた API 管理プラットフォームをすぐに利用可能。 ([ソースコード](https://github.com/TykTechnologies/tyk)) `MPL-2.0` `Go/Docker/K8S`
