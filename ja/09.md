### ネットワークユーティリティ / Network Utilities

**[`^ 目次に戻る ^`](../README.ja.md#目次)**

コンピューターネットワークの管理・監視・トラブルシューティングを支援するツールやソフトウェア。

_関連: [awesome-sysadmin/Monitoring](https://github.com/awesome-foss/awesome-sysadmin#monitoring)_

- [beelzebub](https://beelzebub-honeypot.com/) `⚠` - サイバー攻撃の検知と分析のため、高い安全性を備えた環境を提供するハニーポットフレームワーク。 ([ソースコード](https://github.com/beelzebub-labs/beelzebub)) `MIT` `Docker/K8S/Go`
- [Canary Tokens](https://canarytokens.org) - 不正アクセスを検知するための軽量な埋め込み型ハニーポットトリガー「カナリアトークン」を生成するツール。 ([ソースコード](https://github.com/thinkst/opencanary)) `BSD-3-Clause` `Docker/Python`
- [MyIP](https://ipcheck.ing) `⚠` - オールインワンの IP ツールボックス。自分の IP アドレスや IP の位置情報の確認、DNS リークチェック、WebRTC 接続の検査、速度テスト、ping テスト、MTR テスト、Web サイトの稼働確認などを手軽に行える。 ([デモ](https://ipcheck.ing), [ソースコード](https://github.com/jason5ng32/MyIP)) `MIT` `Nodejs/Docker`
- [MySpeed](https://myspeed.dev/) - インターネット回線速度を最大 30 日分表示できる速度テスト分析ソフトウェア。 ([ソースコード](https://github.com/gnmyt/myspeed)) `MIT` `Docker/Nodejs`
- [NetAlertX](https://netalertx.com/) - ネットワーク侵入者・在席検知ツール。ネットワークに接続されたデバイスをスキャンし、未知の新しいデバイスを見つけると通知する。 ([ソースコード](https://github.com/netalertx/NetAlertX)) `GPL-3.0` `Docker`
- [PlugNPiN](https://deepspace2.github.io/PlugNPiN) - 特定のラベルを持つコンテナを自動で収集し、Pi-Hole/AdGuard Home にローカル DNS/CNAME エントリを、Nginx Proxy Manager にプロキシホストを作成するツール。 ([ソースコード](https://github.com/deepspace2/plugnpin)) `GPL-3.0` `Docker`
- [Speed Test by OpenSpeedTest™](https://openspeedtest.com/) - HTML5 製のネットワーク性能測定ツール。 ([ソースコード](https://github.com/openspeedtest/Speed-Test)) `MIT` `Docker`
- [Speedtest Tracker](https://docs.speedtest-tracker.dev/) - インターネット接続の性能と稼働状況を監視するツール。 ([ソースコード](https://github.com/alexjustesen/speedtest-tracker)) `MIT` `Docker/K8S`
- [Upsnap](https://github.com/seriousm4x/UpSnap) - シンプルな Wake on LAN (WOL) ダッシュボードアプリ。ネットワーク上のデバイスを起動し、現在の状態を確認できる。 `MIT` `Go/Docker`
- [Wakupator](https://github.com/Gibus21250/Wakupator) - ネットワークトラフィックに基づいてマシンを起動する Wake On LAN マネージャー。 `MIT` `C`
- [whois](https://github.com/KincaidYang/whois) - ドメイン、IP アドレス、CIDR プレフィックス、ASN 向けの WHOIS/RDAP 照会 API。統一された JSON 出力、キャッシュ、API キー認証、一括照会、AI アシスタント向けの MCP に対応。 ([デモ](https://whois.ddnsip.cn/example.com)) `MIT` `Go/Docker`

### パスワードマネージャー / Password Managers

**[`^ 目次に戻る ^`](../README.ja.md#目次)**

[パスワードマネージャー](https://en.wikipedia.org/wiki/Password_manager)は、ローカルアプリケーションやオンラインサービスのパスワードを保存・生成・管理するためのソフトウェア。

- [AliasVault](https://www.aliasvault.net) - メールエイリアス生成機能とメールサーバーを内蔵した、エンドツーエンド暗号化パスワードマネージャー。 ([ソースコード](https://github.com/aliasvault/aliasvault)) `MIT` `Docker`
- [Bitwarden](https://bitwarden.com/) `⚠` - Web アプリ、ブラウザ拡張機能、モバイルアプリを備えたパスワードマネージャー。 ([ソースコード](https://github.com/bitwarden/server)) `AGPL-3.0` `Docker/C#`
- [Passbolt](https://www.passbolt.com/) - チームで共有できるパスワードマネージャー。 ([ソースコード](https://github.com/passbolt/passbolt_api)) `AGPL-3.0` `PHP/deb/K8S/Docker`
- [PassIt](https://passit.io/) - グループやユーザー単位の共有機能を備えたシンプルなパスワードマネージャー。管理画面はない。 ([デモ](https://app.passit.io/), [ソースコード](https://gitlab.com/passit)) `AGPL-3.0` `Docker/Python`
- [Psono](https://psono.com/) - 企業向けパスワードマネージャー。 ([デモ](https://www.psono.pw), [ソースコード](https://gitlab.com/esaqa/psono/psono-fileserver)) `Apache-2.0` `Python`
- [Teampass](https://teampass.net/) - パスワードを共同で管理するためのパスワードマネージャー。共有・チーム用パスワードはすべて 1 つの共通鍵で暗号化され、サーバー側のファイルとデータベースに保存される。Apache、MySQL、PHP が動く任意のサーバーで動作。 ([ソースコード](https://github.com/nilsteampassnet/TeamPass)) `GPL-3.0` `PHP`
- [Vaultwarden](https://github.com/dani-garcia/vaultwarden) - Rust で書かれた軽量な Bitwarden サーバー API 実装。 `GPL-3.0` `Rust/Docker`

### ペーストビン / Pastebins

**[`^ 目次に戻る ^`](../README.ja.md#目次)**

[ペーストビン](https://en.wikipedia.org/wiki/Pastebin)は、コードやテキストを共有・保存するためのオンラインコンテンツホスティングサービス。

- [1time](https://1time.io) - ゼロ知識型のワンタイムシークレット共有サービス。パスワード、API キー、ファイル用の使い捨てリンクを作成できる。ブラウザ側で暗号化されるため平文がサーバーに届くことはなく、許可された閲覧回数 (デフォルトは 1 回) を超えると自動消滅する。 ([デモ](https://1time.io), [ソースコード](https://github.com/shingrus/1time.io)) `MIT` `Docker`
- [BinPastes](https://github.com/querwurzel/BinPastes) - クライアント側暗号化、全文検索、ワンタイムメッセージに対応したミニマルなペーストビン。シンプルな導入を求める 1 人〜少人数のユーザー向け。 `Apache-2.0` `Java`
- [ByteStash](https://github.com/jordan-dalby/ByteStash) - シンプルな Web インターフェイスを備えたペーストビン兼ファイル保存サービス。シンタックスハイライト、任意のユーザー認証、公開共有に対応。 ([デモ](https://github.com/jordan-dalby/ByteStash?tab=readme-ov-file#demo)) `GPL-3.0` `Docker`
- [Chiyogami](https://github.com/rhee876527/chiyogami) - API、クライアント側暗号化、ユーザーアカウント、シンタックスハイライト、Markdown レンダリングなどを備えたペーストビン。 ([デモ](https://chiyogami.myaddr.dev/)) `BSD-3-Clause` `Docker`
- [dpaste](https://dpaste.org/) - テキストとコードの複数オプションを備え、覚えやすい短縮 URL を発行するシンプルなペーストビン。 ([ソースコード](https://github.com/DarrenOfficial/dpaste)) `MIT` `Docker/Python`
- [lesma](https://lesma.eu) - ブラウザからもコマンドラインからも使いやすいシンプルなペーストアプリ。 ([デモ](https://lesma.eu), [ソースコード](https://gitlab.com/ogarcia/lesma)) `GPL-3.0` `Rust/Docker`
- [Local Content Share](https://github.com/Tanq16/local-content-share) - ローカルネットワーク内でテキストスニペットやファイルを保存・共有できるツール。 `MIT` `Docker/Go`
- [not-th.re](https://not-th.re) - クライアント側暗号化に対応し、ブラウザベースのコードエディタ Monaco を搭載したシンプルなペースト共有プラットフォーム。 ([デモ](https://not-th.re), [ソースコード](https://github.com/not-three/main)) `AGPL-3.0` `Nodejs/Docker`
- [Opengist](https://opengist.io) - Git を基盤としたペーストビン。 ([デモ](https://demo.opengist.io), [ソースコード](https://github.com/thomiceli/opengist)) `AGPL-3.0` `Docker/Go/Nodejs`
- [paaster](https://paaster.io) - シンプルさを目指して作られたエンドツーエンド暗号化ペーストビン。 ([ソースコード](https://github.com/WardPearce/paaster)) `AGPL-3.0` `Docker`
- [pacebin](https://git.crueter.xyz/crueter/pacebin) - 実行ファイルの小ささ、移植性、設定の容易さを重視した超ミニマルなペーストビン兼ファイルアップロードサービス。 ([デモ](https://paste.crueter.xyz)) `AGPL-3.0` `C`
- [Password Pusher](https://pwpush.com) - パスワード (またはテキスト) を Web 経由で安全に伝えるための非常にシンプルなアプリ。パスワードは一定の閲覧回数または時間の経過後に自動で失効する。 ([ソースコード](https://github.com/pglombardo/PasswordPusher)) `Apache-2.0` `Docker/K8S/Ruby`
- [Pastefy](https://pastefy.app/) - 美しくシンプルで導入しやすいペーストビン。任意のクライアント側暗号化、マルチタブのペースト、API、ハイライト付きエディタなどを備える。 ([ソースコード](https://github.com/interaapps/pastefy), [クライアント](https://github.com/topics/pastefy-addon)) `MIT` `Docker/K8S/Java`
- [PrivateBin](https://privatebin.info/) - ホストするデータをサーバーが一切知らない、ミニマルなペーストビン兼掲示板。 ([デモ](https://privatebin.net/), [ソースコード](https://github.com/PrivateBin/PrivateBin)) `Zlib` `PHP`

- [Snipo](https://github.com/MohamedElashri/snipo) - コードやテキストのスニペットをフォルダー、タグで整理・保存できる軽量なセルフホスト型スニペットマネージャー。API と GitHub Gist 同期に対応。 ([デモ](https://snipo.melashri.dev/)) `AGPL-3.0` `Go/Docker`
