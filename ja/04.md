### データベース管理 / Database Management

**[`^ 目次に戻る ^`](../README.ja.md#目次)**

[データベース](https://en.wikipedia.org/wiki/Database)管理用の Web インターフェース。データベースの分析・可視化ツールも含む。

_関連: [分析](01.md#分析--analytics), [自動化](01.md#自動化--automation)_

_参考: [dbdb.io - Database of Databases](https://dbdb.io/)_

- [Adminer](https://www.adminer.org/) - PHP ファイル 1 つで動くデータベース管理ツール。MySQL、MariaDB、PostgreSQL、SQLite、MS SQL、Oracle、Elasticsearch、MongoDB などに対応。 ([ソースコード](https://github.com/vrana/adminer)) `Apache-2.0/GPL-2.0` `PHP`
- [Azimutt](https://azimutt.app) - 大規模で複雑な実運用データベース向けのビジュアル探索ツール。スキーマとデータの探索、ドキュメント化、拡張に加え、分析やガイドラインも得られる。 ([デモ](https://azimutt.app/gallery/gospeak), [ソースコード](https://github.com/azimuttapp/azimutt)) `MIT` `Elixir/Nodejs/Docker`
- [Baserow](https://baserow.io/) - 専門知識なしで独自のデータベースを作成できるツール（Airtable の代替）。 ([ソースコード](https://gitlab.com/baserow/baserow)) `MIT` `Docker`
- [Bytebase](https://www.bytebase.com/) - DevOps チーム向けの安全なデータベーススキーマ変更・バージョン管理ツール。MySQL、PostgreSQL、TiDB、ClickHouse、Snowflake に対応。 ([ソースコード](https://github.com/bytebase/bytebase)) `MIT` `Docker/K8S/Go`
- [Chartbrew](https://chartbrew.com) - データベースや API に直接接続し、そのデータから美しいチャートを作成できるツール。 ([デモ](https://app.chartbrew.com/live-demo), [ソースコード](https://github.com/chartbrew/chartbrew)) `MIT` `Nodejs/Docker`
- [ChartDB](https://chartdb.io/) - クエリ 1 本で DB を可視化・設計できるデータベース図エディター。 ([デモ](https://app.chartdb.io), [ソースコード](https://github.com/chartdb/chartdb)) `AGPL-3.0` `Nodejs/Docker`
- [CloudBeaver](https://dbeaver.com/) - PostgreSQL、MySQL、SQLite などに対応したデータベース管理ツール。DBeaver の Web／ホスト版。 ([ソースコード](https://github.com/dbeaver/cloudbeaver)) `Apache-2.0` `Docker`
- [d9](https://d9.webcapsule.io) - 直感的な管理画面で SQL データベースを安全な API に変換するツール。データプラットフォーム兼ヘッドレス CMS（Directus のフォーク）。 ([ソースコード](https://github.com/LaWebcapsule/d9)) `GPL-3.0` `Nodejs`
- [Databunker](https://databunker.org/) - 個人データや PII を扱う、ネットワーク型・セルフホスト・GDPR 準拠のセキュアなデータベース。 ([ソースコード](https://github.com/securitybunker/databunker)) `MIT` `Docker`
- [datannur](https://datannur.com) - 構造化データファイルやデータベースを文書化・探索するための軽量データカタログ。 ([デモ](https://dev.datannur.com/), [ソースコード](https://github.com/datannur/datannur)) `MIT` `Python`
- [Datasette](https://datasette.io/) - 簡単なインポート／エクスポートとデータベース管理機能を備えた、データ探索・公開ツール。 ([ソースコード](https://github.com/simonw/datasette)) `Apache-2.0` `Python/Docker`
- [Evidence](https://evidence.dev) - コードベースの BI ツール。SQL と Markdown で書いたレポートを Web サイトとして出力する。 ([ソースコード](https://github.com/evidence-dev/evidence)) `MIT` `Nodejs`
- [LibreDB Studio](https://libredb.org) - PostgreSQL、MySQL、Oracle、SQL Server、MongoDB、Redis、ClickHouse、DuckDB などに対応したブラウザーベースの SQL IDE。SSO、監査ログ、ER 図、自前のモデルキーによる AI 支援（任意）を備える（DataGrip、DBeaver、CloudBeaver の代替）。 ([ソースコード](https://github.com/libredb/libredb-studio)) `MIT` `Docker/K8S`
- [Limbas](https://www.limbas.com/en/) - データベース駆動の業務アプリケーションを作成するためのフレームワーク。グラフィカルなデータベースフロントエンドとして、データの効率的な処理と使いやすいデータベースアプリの柔軟な開発を実現。 ([ソースコード](https://github.com/limbas/limbas)) `GPL-2.0` `PHP`
- [Mathesar](https://mathesar.org/) - 技術レベルを問わず、データを共同で管理できる直感的な UI。Postgres ベースで、既存 DB への接続も新規構築も可能。 ([ソースコード](https://github.com/mathesar-foundation/mathesar)) `GPL-3.0` `Docker/Python`
- [OrcaQ](https://orca-q.com) - AI アシスタントを内蔵し、複数種類のデータベースを管理・クエリ・探索できるモダンなデータベースクライアント兼 IDE。 ([ソースコード](https://github.com/cin12211/orca-q)) `MIT` `Nodejs/deb/Docker`
- [StackRender](https://stackrender.io/) - PostgreSQL、MySQL、MariaDB、SQLite、SQL Server、Oracle に対応したデータベーススキーマ設計・SQL マイグレーション生成ツール。 ([デモ](https://app.stackrender.io/), [ソースコード](https://github.com/stackrender/stackrender)) `AGPL-3.0` `Nodejs/Docker`

### DNS / DNS

**[`^ 目次に戻る ^`](../README.ja.md#目次)**

_参考: [awesome-sysadmin/DNS - Servers](https://github.com/awesome-foss/awesome-sysadmin#dns---servers), [awesome-sysadmin/DNS - Control Panels & Domain Management](https://github.com/awesome-foss/awesome-sysadmin#dns---control-panels--domain-management)_

- [blocky](https://0xerr0r.github.io/blocky/latest/) - ローカルネットワーク向けの高速・軽量な広告ブロック DNS プロキシ。多機能（Pi-hole の代替）。 ([ソースコード](https://github.com/0xERR0R/blocky)) `Apache-2.0` `Go/Docker`
- [Maza ad blocking](https://maza-ad-blocking.andros.dev/) - ローカルの広告ブロッカー。Pi-hole に似ているが、OS 上でローカルに動作する。 ([ソースコード](https://github.com/tanrax/maza-ad-blocking)) `Apache-2.0` `Shell`
- [Numa](https://numa.rs/) - DNSSEC 検証付き再帰解決、DoH／DoT／Oblivious DoH、一時的なオーバーライド、ローカルサービス用ドメインを備えた広告ブロック DNS リゾルバー。Rust の単一バイナリで動作（Pi-hole、AdGuard Home、NextDNS の代替）。 ([ソースコード](https://github.com/razvandimescu/numa)) `MIT` `Rust/Docker/Nix`
- [Pi-hole](https://pi-hole.net/) - インターネット広告を遮断するブラックホール。管理・監視用の GUI 付き。 ([ソースコード](https://github.com/pi-hole/pi-hole)) `EUPL-1.2` `Shell/PHP/Docker`
- [Technitium DNS Server](https://technitium.com/dns/) - 広告ブロック機能を備えた権威／再帰 DNS サーバー。 ([ソースコード](https://github.com/TechnitiumSoftware/DnsServer)) `GPL-3.0` `Docker/C#`

### 文書管理：図書館システム（ILS） / Document Management - Integrated Library Systems (ILS)

**[`^ 目次に戻る ^`](../README.ja.md#目次)**

[統合図書館システム](https://en.wikipedia.org/wiki/Integrated_library_system)は図書館向けの業務基幹システム（ERP）で、所蔵資料、発注、支払い、貸出利用者の管理に用いられる。

_関連: [コンテンツ管理システム（CMS）](03.md#コンテンツ管理システムcms--content-management-systems-cms), [アーカイブ・デジタル保存](01.md#アーカイブデジタル保存--archiving-and-digital-preservation-dp)_

- [Koha](https://koha-community.org/) - エンタープライズ級の ILS。受入、貸出、目録作成、ラベル印刷、インターネット非接続時のオフライン貸出など多数のモジュールを備える。 ([デモ](https://koha-community.org/demo/), [ソースコード](https://github.com/Koha-Community/Koha)) `GPL-3.0` `Perl`
