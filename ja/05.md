### ファイル転送：オブジェクトストレージ・ファイルサーバー / File Transfer - Object Storage & File Servers

**[`^ 目次に戻る ^`](../README.ja.md#目次)**

[オブジェクトストレージ](https://en.wikipedia.org/wiki/Object_storage)は、データをオブジェクトとして管理するデータストレージ。データをファイル階層として管理するファイルシステムや、セクター・トラック内のブロックとして管理するブロックストレージとは異なる方式。

- [GarageHQ](https://garagehq.deuxfleurs.fr/) - さまざまな用途に対応できる、地理分散型の S3 互換ストレージサービス。 ([ソースコード](https://git.deuxfleurs.fr/Deuxfleurs/garage)) `AGPL-3.0` `Docker/Rust`
- [Harbor](https://goharbor.io/) - コンテンツの保存・署名・スキャンを行うクラウドネイティブなイメージレジストリ。 ([ソースコード](https://github.com/goharbor/harbor)) `Apache-2.0` `Docker/K8S`
- [SeaweedFS](https://github.com/seaweedfs/seaweedfs) - WebDAV、S3 API、FUSE マウント、HDFS などに対応したオープンソースの分散ファイルシステム。大量の小さなファイルに最適化され、容量の追加も容易。 `Apache-2.0` `Go`
- [Zenko CloudServer](https://www.zenko.io/cloudserver) - フロントエンドで Amazon S3 プロトコルを実装し、バックエンドで Azure や Google を含む複数クラウドへのストレージ機能を提供。 ([ソースコード](https://github.com/scality/cloudserver)) `Apache-2.0` `Docker/Nodejs`
- [ZOT OCI Registry](https://zotregistry.dev) - 本番環境で使える、ベンダー中立な OCI ネイティブのコンテナイメージレジストリ。 ([デモ](https://zothub.io), [ソースコード](https://github.com/project-zot/zot)) `Apache-2.0` `Go/Docker`

- [bittorrent-tracker](https://webtorrent.io/) - シンプルで堅牢な BitTorrent トラッカー（クライアント・サーバー）実装。 ([ソースコード](https://github.com/webtorrent/bittorrent-tracker)) `MIT` `Nodejs`

- [PrivyDrop](https://www.privydrop.app) - WebRTC ベースの、シンプルで使いやすくレジューム可能な P2P テキスト・画像・ファイル転送ツール。 ([ソースコード](https://github.com/david-bai00/PrivyDrop)) `MIT` `Docker/Nodejs`
- [qBittorrent](https://www.qbittorrent.org/) - リモートアクセス用の高機能 Web UI を備えた無料のクロスプラットフォーム BitTorrent クライアント。 ([ソースコード](https://github.com/qbittorrent/qBittorrent)) `GPL-2.0` `C++`
- [slskd](https://github.com/slskd/slskd) `⚠` - Soulseek ファイル共有ネットワーク向けのモダンなクライアント・サーバーアプリ。 `AGPL-3.0` `Docker/C#`
- [Transmission](https://transmissionbt.com/) - 高速で使いやすい無料の BitTorrent クライアント。 ([ソースコード](https://github.com/transmission/transmission)) `GPL-3.0` `C++/deb`
- [Webtor](https://github.com/webtor-io/self-hosted) - 音声・動画を即時ストリーミングできる Web ベースの Torrent クライアント。 ([デモ](https://webtor.io)) `MIT` `Docker`
