### URL 短縮 / URL Shorteners

**[`^ 目次に戻る ^`](../README.ja.md#目次)**

[URL 短縮](https://en.wikipedia.org/wiki/URL_shortening)とは、[URL](https://en.wikipedia.org/wiki/Uniform_Resource_Locator) を大幅に短くしつつ、目的のページへ転送できるようにすること。ホスティングする前に、URL 短縮サービスの[欠点](https://en.wikipedia.org/wiki/URL_shortening#Disadvantages)を確認すること。

- [bit](https://github.com/sjdonado/bit) - 高速・軽量で省リソースなコンパイル型 URL 短縮サービス。 `MIT` `Docker/Crystal`
- [Chhoto URL](https://chhoto.link) - 余計な機能のないシンプルで超高速な URL 短縮サービス（simply-shorten のフォーク）。 ([デモ](https://github.com/SinTan1729/chhoto-url?tab=readme-ov-file#demo), [ソースコード](https://github.com/SinTan1729/chhoto-url), [クライアント](https://github.com/SinTan1729/chhoto-url/blob/main/TOOLS.md)) `MIT` `Rust/Docker`
- [clink](https://git.crueter.xyz/crueter/clink) - 純粋な C で書かれた超ミニマルなリンク短縮サービス。実行ファイルの小ささ、移植性、設定の容易さを重視。 ([デモ](https://short.crueter.xyz)) `AGPL-3.0` `C`
- [Flink](https://gitlab.com/rtraceio/web/flink) - QR コードやサイトに埋め込めるリンクプレビューを作成し、メタデータをクロール・スクレイピング。 ([デモ](https://flink.is)) `MIT` `Docker`
- [Kutt](https://kutt.to) - カスタムドメインとカスタム URL に対応したモダンな URL 短縮サービス。 ([デモ](https://kutt.to), [ソースコード](https://github.com/thedevs-network/kutt)) `MIT` `Nodejs/Docker`
- [rs-short](https://git.42l.fr/42l/rs-short) - Rust 製の軽量リンク短縮サービス。キャッシュ、スパムボット対策、フィッシング検出などの機能を備える。 ([デモ](https://s.42l.fr/)) `MPL-2.0` `Rust`
- [Shlink](https://shlink.io) - REST API とコマンドラインインターフェースを備えた URL 短縮サービス。公式のプログレッシブ Web アプリと Docker イメージも提供。 ([ソースコード](https://github.com/shlinkio/shlink), [クライアント](https://shlink.io/apps)) `MIT` `PHP/Docker`
- [Simple-URL-Shortener](https://github.com/azlux/Simple-URL-Shortener) - KISS 原則の URL 短縮サービス。公開・非公開（アカウント制）に対応。ミニマルで軽量、依存関係なし。 ([デモ](https://u.azlux.fr)) `MIT` `PHP`
- [YOURLS](https://yourls.org/) - 独自の URL 短縮サービスを運用できる PHP スクリプト群。パスワード保護、URL のカスタマイズ、ブックマークレット、統計、API、プラグイン、JSONP などに対応。 ([ソースコード](https://github.com/YOURLS/YOURLS)) `MIT` `PHP`

- [SentryShot](https://codeberg.org/SentryShot/sentryshot) - 映像監視管理システム。 `GPL-2.0` `Docker/Rust`
- [Strix](https://github.com/eduard256/Strix) - IP カメラの有効なストリーム URL を自動検出し、そのまま使える Frigate と go2rtc の設定を生成。 `MIT` `Go/Docker`
- [Viseron](https://viseron.netlify.app/) - セルフホスト型でローカル完結の NVR・AI コンピュータビジョンソフトウェア。物体検出、動体検知、顔認識などの機能により、自宅やオフィスなど監視したい場所を見守れる。 ([ソースコード](https://github.com/roflcoopter/viseron)) `MIT` `Docker`
- [Zoneminder](https://www.zoneminder.com/) - IP、USB、アナログカメラに対応した CCTV（監視カメラ）ソフトウェア。 ([ソースコード](https://github.com/ZoneMinder/ZoneMinder)) `GPL-2.0` `PHP/deb`

### Web サーバー / Web Servers

**[`^ 目次に戻る ^`](../README.ja.md#目次)**

Web サーバーとリバースプロキシ。[Web サーバー](https://en.wikipedia.org/wiki/Web_server)は、[HTTP](https://en.wikipedia.org/wiki/Hypertext_Transfer_Protocol)（Web コンテンツ配信のために作られたネットワークプロトコル）またはその安全版である [HTTPS](https://en.wikipedia.org/wiki/HTTPS) でリクエストを受け付けるソフトウェアとそれを支えるハードウェア。[リバースプロキシ](https://en.wikipedia.org/wiki/Reverse_proxy)は、クライアントからは通常の Web サーバーに見えるが、実際には 1 台以上の通常の Web サーバーへリクエストを転送する仲介役にすぎないプロキシサーバー。

_関連: [プロキシ](10.md#プロキシ--proxy)_

- [Algernon](https://algernon.roboticoverlords.org/) - Lua、Markdown、HTTP/2、QUIC、Redis、PostgreSQL に対応した、自己完結型の小さな純 Go 製 Web サーバー。 ([ソースコード](https://github.com/xyproto/algernon)) `BSD-3-Clause` `Go/Docker`
- [Apache HTTP Server](https://httpd.apache.org/) - 最新の HTTP 標準に準拠した HTTP サービスを提供する、安全・効率的で拡張性の高いサーバー。 ([ソースコード](https://svn.apache.org/repos/asf/httpd/httpd/trunk/)) `Apache-2.0` `C/deb/Docker`
- [BunkerWeb](https://www.bunkerweb.io) - Web サービスを保護する次世代 Web アプリケーションファイアウォール（WAF）。 ([デモ](https://demo.bunkerweb.io), [ソースコード](https://github.com/bunkerity/bunkerweb), [クライアント](https://docs.bunkerweb.io/latest/plugins/)) `AGPL-3.0` `deb/Docker/K8S/Python`
- [Caddy](https://caddyserver.com/) - 自動 HTTPS を備えた、強力でエンタープライズ対応のオープンソース Web サーバー。 ([ソースコード](https://github.com/caddyserver/caddy)) `Apache-2.0` `Go/deb/Docker`
- [Ferron](https://ferron.sh/) - Rust 製の高速でメモリ安全な Web サーバー。 ([ソースコード](https://github.com/ferronweb/ferron)) `MIT` `Rust/Docker/deb`
- [go-doxy](https://github.com/yusing/godoxy) - Web UI、Docker 連携、トラフィックに応じたコンテナの自動停止・起動を備えた、軽量・シンプル・高性能なリバースプロキシ。 `MIT` `Docker/Go`
- [HAProxy](https://www.haproxy.org/) - TCP および HTTP ベースのアプリケーション向けに高可用性、負荷分散、プロキシ機能を提供する、非常に高速で信頼性の高いリバースプロキシ。 ([ソースコード](https://git.haproxy.org/?p=haproxy.git;a=tree)) `GPL-2.0` `C/deb/Docker`
- [Lighttpd](https://www.lighttpd.net/) - 高性能環境向けに最適化された、安全・高速・標準準拠で非常に柔軟な Web サーバー。 ([ソースコード](https://git.lighttpd.net/lighttpd/lighttpd1.4)) `BSD-3-Clause` `C/deb/Docker`
- [Nginx Proxy Manager](https://nginxproxymanager.com/) - シンプルかつ強力なインターフェースで Nginx のプロキシホストを管理する Docker コンテナ。 ([ソースコード](https://github.com/NginxProxyManager/nginx-proxy-manager)) `MIT` `Docker`
- [NGINX](https://nginx.org/en/) - HTTP サーバー兼リバースプロキシ、メールプロキシ、汎用 TCP/UDP プロキシサーバー。 ([ソースコード](https://github.com/nginx/nginx)) `BSD-2-Clause` `C/deb/Docker`
- [Pangolin](https://digpangolin.com/) - ダッシュボード UI、アクセス制御、WireGuard ベースのトンネルを備えた ID 認識型のトンネル型リバースプロキシ（Cloudflare Tunnel、Tailscale の代替）。 ([ソースコード](https://github.com/fosrl/pangolin)) `AGPL-3.0` `Docker`

- [Traefik](https://traefik.io/) - マイクロサービスのデプロイを容易にする HTTP リバースプロキシ兼ロードバランサー。 ([ソースコード](https://github.com/traefik/traefik)) `MIT` `Go/Docker`
- [UUSEC WAF](https://waf.uusec.com/) - AI とセマンティック技術を用いた業界トップクラスの高性能 Web アプリケーションファイアウォール兼 API セキュリティゲートウェイ（nginx のフォーク）。 ([ソースコード](https://github.com/Safe3/uusec-waf)) `GPL-3.0` `C/Lua/Docker`
- [Vinyl Cache](https://vinyl-cache.org/) - Web アプリケーションアクセラレーター / キャッシュ型 HTTP リバースプロキシ（旧 Varnish）。 ([ソースコード](https://code.vinyl-cache.org/vinyl-cache/vinyl-cache)) `BSD-2-Clause` `Go/deb/Docker`
- [Zoraxy](https://zoraxy.aroz.org/) - 汎用の HTTP リバースプロキシ兼転送ツール。 ([ソースコード](https://github.com/tobychui/zoraxy)) `AGPL-3.0` `Go/Docker`

_参考: [Wikimatrix](https://www.wikimatrix.org/), [List of wiki software - Wikipedia](https://en.wikipedia.org/wiki/List_of_wiki_software), [Comparison of wiki software - Wikipedia](https://en.wikipedia.org/wiki/Comparison_of_wiki_software)_

- [AmuseWiki](https://amusewiki.org/) - Emacs Muse マークアップをベースとし、オリジナル実装とほぼ互換性を保つ Wiki。読み取り専用サイト、モデレーション付き Wiki、完全オープンな Wiki、さらには非公開サイトとしても運用可能。 ([ソースコード](https://github.com/melmothx/amusewiki)) `GPL-1.0` `Perl/Docker`
- [BookStack](https://www.bookstackapp.com/) - 情報を整理・保存。ドキュメントを本のような形式で管理。 ([デモ](https://www.bookstackapp.com/#demo), [ソースコード](https://codeberg.org/bookstack/bookstack)) `MIT` `PHP/Docker`
- [django-wiki](https://github.com/django-wiki/django-wiki) - 簡単に組み込める高機能な Wiki システム。優れたインターフェースを持ち、Django モデルで知識を保存。 ([デモ](https://demo.django-wiki.org/)) `GPL-3.0` `Python`
- [docmost Community Edition](https://docmost.com/) - 共同編集可能な Wiki・ドキュメントソフトウェア（Confluence、Notion の代替）。 ([ソースコード](https://github.com/docmost/docmost)) `AGPL-3.0` `Docker/Nodejs`
- [Documize](https://documize.com) - ワークフローを内蔵したモダンなドキュメント + Wiki ソフトウェア。単一の実行バイナリで、MySQL/Percona を用意するだけで動作。 ([ソースコード](https://github.com/documize/community)) `AGPL-3.0` `Go`
- [Dokuwiki](https://www.dokuwiki.org/DokuWiki) - 使いやすく軽量で標準準拠の Wiki エンジン。シンプルな記法により Wiki の外でもデータを読める。全データをプレーンテキストファイルに保存するため、データベースは不要。 ([ソースコード](https://github.com/dokuwiki/dokuwiki)) `GPL-2.0` `PHP`
- [Feather Wiki](https://feather.wiki) - 個人用の非線形ノート、データベース、Wiki を作成できる、超高速で無限に拡張可能なツール。完全に自己完結し、ブラウザー上で動作し、サイズはわずか 58 KB。 ([デモ](https://feather.wiki/?page=gallery#wikis), [ソースコード](https://codeberg.org/Alamantus/FeatherWiki), [クライアント](https://feather.wiki/?page=gallery#extensions)) `AGPL-3.0` `Javascript`
- [Gitit](https://github.com/jgm/gitit) - ページとアップロードファイルを Git リポジトリに保存する Wiki プログラム。VCS のコマンドラインツールまたは Wiki の Web インターフェースから編集可能。 `GPL-2.0` `Haskell`
- [LeafWiki](https://github.com/perber/leafwiki) - フィードではなくフォルダーで考える人のための高速 Wiki。素早い編集、ツリーナビゲーション、ディスク上の Markdown。 ([デモ](https://demo.leafwiki.com)) `MIT` `Docker/Go`
- [Mediawiki](https://www.mediawiki.org/wiki/MediaWiki) - Wikipedia をはじめとする全 Wikimedia プロジェクトを支え、毎月数億人のユーザーにサービスを提供する Wiki ソフトウェア。 ([デモ](https://en.wikipedia.org/wiki/Main_Page), [ソースコード](https://phabricator.wikimedia.org/source/mediawiki/)) `GPL-2.0` `PHP`
- [Otter Wiki](https://otterwiki.com/) - Markdown を使うシンプルで使いやすい Wiki ソフトウェア。 ([ソースコード](https://github.com/redimp/otterwiki)) `MIT` `Docker`
- [PmWiki](https://www.pmwiki.org) - Web サイトを共同で作成・保守するための Wiki ベースのシステム。 `GPL-3.0` `PHP`
- [Raneto](https://raneto.com/) - 静的な Markdown ファイルを使うナレッジベースプラットフォーム。 ([ソースコード](https://github.com/ryanlelek/Raneto)) `MIT` `Nodejs`
- [TiddlyWiki](https://tiddlywiki.com/) - 再利用可能な非線形の個人用 Web ノート。 ([ソースコード](https://github.com/TiddlyWiki/TiddlyWiki5)) `BSD-3-Clause` `Nodejs`
- [Tiki](https://tiki.org/HomePage) - 最も多くの機能を内蔵した Wiki / CMS / グループウェア。 ([デモ](https://tiki.org/Try-Tiki), [ソースコード](https://gitlab.com/tikiwiki/tiki)) `LGPL-2.1` `PHP`
- [W](https://w.club1.fr) - 軽量・マルチユーザー対応のフラットファイル DB 型 Wiki エンジン。Markdown/HTML/CSS/JS を使って Web ブラウザーで素早くページを作成・編集できる。各ページのスタイルを個別にカスタマイズすることを推奨している点が他の Wiki との大きな違い。 ([ソースコード](https://github.com/vincent-peugnet/wcms)) `AGPL-3.0` `PHP`
- [WackoWiki](https://wackowiki.org/) - 軽量で導入が簡単な多言語対応 Wiki エンジン。 ([ソースコード](https://github.com/WackoWiki/wackowiki)) `BSD-3-Clause` `PHP`
- [Wiki-Go](https://leomoon.com/downloads/web-apps/wiki-go/) - データベース不要の、モダンで多機能なフラットファイル Wiki プラットフォーム。 ([デモ](https://wikigo.leomoon.com), [ソースコード](https://github.com/leomoon-studios/wiki-go)) `GPL-3.0` `Go/Docker`
- [Wiki.js](https://js.wiki/) - Git と Markdown を使う、モダン・軽量・高機能な Wiki アプリ。 ([デモ](https://docs.requarks.io), [ソースコード](https://github.com/Requarks/wiki)) `AGPL-3.0` `Nodejs/Docker/K8S`
- [WikiDocs](https://www.wikidocs.app/) - データベース不要の Markdown フラットファイル Wiki エンジン。 ([ソースコード](https://github.com/Zavy86/WikiDocs)) `MIT` `PHP/Docker`
- [WiKiss](https://wikiss.tuxfamily.org/) - 使いやすく導入も簡単な Wiki。 ([ソースコード](https://svnweb.tuxfamily.org/listing.php?repname=wikiss/svn&path=%2F&sc=0)) `GPL-2.0` `PHP`
- [XWiki](https://www.xwiki.org) - 強力な拡張ベースのアーキテクチャで機能を拡張できる第 2 世代 Wiki。 ([デモ](https://www.xwikiplayground.org/xwiki/bin/view/Main/), [ソースコード](https://github.com/xwiki/xwiki-platform)) `LGPL-2.1` `Java/Docker/deb`
- [Zim](https://zim-wiki.org/) - Wiki ページ群を管理するためのグラフィカルなテキストエディタ。各ページには他ページへのリンク、簡単な書式、画像を含められる。 ([ソースコード](https://github.com/zim-desktop-wiki/zim-desktop-wiki)) `GPL-2.0` `Python/deb`
