### 投票・イベント / Polls and Events

**[`^ 目次に戻る ^`](../README.ja.md#目次)**

- [Christmas Community](https://github.com/Wingysam/Christmas-Community) - 家族全員で欲しいギフトを共有し、プレゼントの重複を防ぐためのシンプルな場を作成できる。 `AGPL-3.0` `Docker/Nodejs`

### プロキシ / Proxy

**[`^ 目次に戻る ^`](../README.ja.md#目次)**

[プロキシ](https://en.wikipedia.org/wiki/Proxy_server)とは、リソースを要求するクライアントとそのリソースを提供するサーバーの間を仲介するサーバーアプリケーション。このセクションではフォワード（送信側）プロキシを扱う。リバースプロキシについては Web サーバーのセクションを参照。

_関連: [Web サーバー](12.md#web-サーバー--web-servers)_

- [g3proxy](https://g3-project.readthedocs.io/projects/g3proxy/en/latest/) - プロキシチェーン、プロトコル検査、MITM インターセプト、ICAP 連携、透過プロキシに対応したフォワードプロキシサーバー。 ([ソースコード](https://github.com/bytedance/g3/tree/master/g3proxy)) `Apache-2.0` `Rust/deb`
- [GitProxy](https://git-proxy.finos.org/) - すべての送信 git push 操作にルールとワークフローを適用し、コンプライアンスを確保する Git 用プロキシ。HTTP/HTTPS と SSH の両プロトコルに対応し、セキュリティスキャンと検証を行う。 ([ソースコード](https://github.com/finos/git-proxy)) `Apache-2.0` `Nodejs/Docker`
- [imagor](https://github.com/cshum/imagor) - libvips をベースにした高速・安全な画像処理サーバー兼 Go ライブラリ。オンデマンドのリサイズ、切り抜き、フィルター、フォーマット変換、画像合成、署名付き URL、高並列処理向けのストリーミングパイプラインを備える。 `Apache-2.0` `Docker`
- [imgproxy](https://imgproxy.net/) - リモート画像のリサイズと変換を行う、高速で安全なスタンドアロンサーバー。 ([ソースコード](https://github.com/imgproxy/imgproxy)) `MIT` `Go/Docker/K8S`
- [Outline Server](https://getoutline.org/) - アクセスキーごとに Shadowsocks インスタンスを実行し、アクセスキー管理用の REST API を備えたプロキシサーバー。 ([ソースコード](https://github.com/OutlineFoundation/outline-server)) `Apache-2.0` `Docker/Nodejs`
- [Privoxy](https://www.privoxy.org) - 高度なフィルタリング機能を持つ非キャッシュ型 Web プロキシ。プライバシー強化、Web ページデータや HTTP ヘッダーの改変、アクセス制御、広告などの不快なインターネット上のゴミの除去が可能。 `GPL-2.0` `C/deb`
- [sish](https://github.com/antoniomika/sish) - SSH のみを使って localhost への HTTP(S)/WS(S)/TCP トンネルを提供（serveo/ngrok の代替）。 `MIT` `Go/Docker`
- [socks5-proxy-server](https://github.com/nskondratev/socks5-proxy-server) - 認証機能と、ユーザー管理およびデータ使用量統計のための Telegram ボットを内蔵した SOCKS5 プロキシサーバー（GB 単位の従量課金時に便利）。Docker 化されておりインストールが簡単。 `Apache-2.0` `Docker`
- [Squid](http://www.squid-cache.org/) - HTTP、HTTPS、FTP などに対応した Web 向けキャッシュプロキシ。頻繁に要求される Web ページをキャッシュして再利用し、帯域幅を削減して応答時間を改善する。 ([ソースコード](https://code.launchpad.net/squid)) `GPL-2.0` `C/deb`
- [Tinyproxy](https://tinyproxy.github.io/) - 軽量な HTTP/HTTPS プロキシデーモン。 ([ソースコード](https://github.com/tinyproxy/tinyproxy)) `GPL-2.0` `C/deb`

### レシピ管理 / Recipe Management

**[`^ 目次に戻る ^`](../README.ja.md#目次)**

[レシピ](https://en.wikipedia.org/wiki/Recipe)を管理するためのソフトウェアとツール。

- [Bar Assistant](https://barassistant.app/) - 材料の登録、カクテルの検索、オリジナルカクテルレシピの作成をしながら自宅のバーを管理できる。 ([デモ](https://demo.barassistant.app/), [ソースコード](https://github.com/karlomikus/bar-assistant)) `MIT` `PHP/Docker`

- [Fork Recipes](https://mikebgrep.github.io/forkapi/latest/clients/) - 料理レシピをシンプルに管理できる。 ([ソースコード](https://github.com/mikebgrep/fork.recipes)) `BSD-3-Clause` `Docker`
- [ManageMeals](https://managemeals.com/) - レシピの管理、URL からのレシピ取り込み、広告や余計な文章なしでの整理が可能。 ([ソースコード](https://github.com/managemeals/manage-meals-web)) `GPL-3.0` `Docker`
- [Mealie](https://nightly.mealie.io/) - マテリアルデザインに着想を得たレシピマネージャー。カテゴリ・タグ管理、買い物リスト、献立プランナー、サイトのカスタマイズ機能を備える。家族全員が使い続けられるよう、シンプルな操作性を重視。 ([デモ](https://demo.mealie.io), [ソースコード](https://github.com/mealie-recipes/mealie)) `MIT` `Python`
- [RecipeSage](https://github.com/julianpoy/recipesage) - 任意の URL からレシピを直接取り込めるレシピ保管、献立管理、買い物リスト管理ツール。 ([デモ](https://recipesage.com)) `AGPL-3.0` `Nodejs`
- [Recipya](https://recipes.musicavis.ca) - 家族全員で楽しめる、すっきりシンプルで強力なレシピマネージャー。 ([デモ](https://recipes.musicavis.ca/guide/login), [ソースコード](https://github.com/reaper47/recipya)) `GPL-3.0` `Docker/Go`
- [Tamari](https://tamariapp.com) - レシピ集を内蔵したレシピ管理 Web アプリ。お気に入りやカテゴリでの整理、買い物リスト作成、献立計画が可能。 ([デモ](https://app.tamariapp.com), [ソースコード](https://github.com/alexbates/Tamari)) `GPL-3.0` `Docker/Python`
- [Vanilla Cookbook](https://vanilla-cookbook.readthedocs.io/en/) - 内部には複雑な機能を備えつつ、ユーザー体験はできるだけすっきりとシンプル（バニラ）に保つよう設計されたレシピマネージャー。 ([ソースコード](https://github.com/jt196/vanilla-cookbook)) `GPL-3.0` `Docker/Nodejs`
- [What To Cook?](https://github.com/kassner/whattocook) - 家にある材料をもとに、今日作るレシピを提案。 `AGPL-3.0` `Docker`

### リモートアクセス / Remote Access

**[`^ 目次に戻る ^`](../README.ja.md#目次)**

コンピューターシステムをリモート管理するための[リモートデスクトップ](https://en.wikipedia.org/wiki/Remote_desktop_software)・[SSH](https://en.wikipedia.org/wiki/Secure_Shell) サーバーと Web インターフェース。

- [Cardea](https://github.com/hectorm/cardea) - アクセス制御、セッション記録、オプションで TPM によるキー保護を備えた SSH 踏み台サーバー。 `EUPL-1.2` `Go/Docker`
- [Engity's Bifröst](https://bifroest.engity.org/) - 高度にカスタマイズ可能な SSH サーバー。複数のユーザー認可方式と、ユーザーセッションの実行場所・方法の選択肢を備える。 ([ソースコード](https://github.com/engity-com/bifroest)) `Apache-2.0` `Go/Docker`
- [Firezone](https://www.firezone.dev/) - WireGuard プロトコルに対応した安全なリモートアクセスゲートウェイ。Web GUI、1 行のインストールスクリプト、多要素認証（MFA）、SSO を提供。 ([ソースコード](https://github.com/firezone/firezone)) `Apache-2.0` `Elixir/Docker`
- [Guacamole](https://guacamole.apache.org) - VNC や RDP などの標準プロトコルに対応した、クライアント不要のリモートデスクトップゲートウェイ。 ([ソースコード](https://github.com/apache/guacamole-server)) `Apache-2.0` `Java/C`
- [MeshCentral](https://meshcentral.com/) - 独自の Web サーバーを運用し、ローカルネットワークやインターネット上のコンピューターをリモートで管理・操作できる。 ([ソースコード](https://github.com/Ylianst/MeshCentral)) `Apache-2.0` `Nodejs`
- [ShellHub](https://www.shellhub.io) - コマンドライン（任意の SSH クライアント）や Web ベースの UI から Linux デバイスにリモートアクセスできるモダンな SSH サーバー（sshd の代替）。 ([ソースコード](https://github.com/shellhub-io/shellhub)) `Apache-2.0` `Docker`
- [Sshwifty](https://github.com/nirui/sshwifty) - Web 向けの SSH・Telnet 接続ツール。 ([デモ](https://sshwifty-demo.nirui.org)) `AGPL-3.0` `Go/Docker`
- [Termix](https://docs.termix.site/) - SSH ターミナル、トンネリング、ファイル編集機能を備えた、クライアント不要の Web ベースのサーバー管理プラットフォーム。 ([ソースコード](https://github.com/Termix-SSH/Termix)) `Apache-2.0` `Docker`
- [Warpgate](https://github.com/warp-tech/warpgate) - クライアント側に追加ソフトウェアが不要な、完全に透過的な SSH、HTTPS、Kubernetes、MySQL、Postgres 向け踏み台/PAM。 `Apache-2.0` `Rust/Docker`

### 検索エンジン / Search Engines

**[`^ 目次に戻る ^`](../README.ja.md#目次)**

[検索エンジン](https://en.wikipedia.org/wiki/Search_engine_(computing))とは、コンピューターシステムに保存された情報を見つけるための[情報検索システム](https://en.wikipedia.org/wiki/Information_retrieval)。[Web 検索エンジン](https://en.wikipedia.org/wiki/Web_search_engine)もこれに含まれる。

- [Aleph](https://aleph.occrp.org/) - 大量の文書（PDF、Word、HTML）と構造化データ（CSV、XLS、SQL）をインデックス化し、手軽に閲覧・検索できるようにするツール。調査報道を主な用途として開発された。 ([デモ](https://aleph.occrp.org/), [ソースコード](https://github.com/alephdata/aleph)) `MIT` `Docker/K8S`
- [Amgix](https://amgix.io) - 柔軟なデプロイと現実の雑多なデータに対応したハイブリッド検索エンジン。 ([デモ](https://findgovdata.org), [ソースコード](https://github.com/amgix/amgix-server), [クライアント](https://github.com/orgs/amgix/repositories)) `AGPL-3.0` `Docker/K8S`
- [Apache Solr](https://lucene.apache.org/solr/) - 全文検索、ヒット箇所のハイライト、ファセット検索、リアルタイムインデックス、動的クラスタリング、リッチドキュメント（Word、PDF など）処理を備えたエンタープライズ検索プラットフォーム。 ([ソースコード](https://github.com/apache/solr)) `Apache-2.0` `Java/Docker/K8S`
- [Fess](https://fess.codelibs.org/) - 強力で導入しやすいエンタープライズ検索サーバー。 ([デモ](https://search.n2sm.co.jp/), [ソースコード](https://github.com/codelibs/fess)) `Apache-2.0` `Java/Docker`
- [Hister](https://hister.org/) - 閲覧した Web サイトを自動でインデックス化する個人用 Web 検索エンジン。オフラインでのローカル結果プレビュー、ローカルファイル、マルチユーザー、オプションのセマンティック検索に対応。 ([デモ](https://demo.hister.org/), [ソースコード](https://github.com/asciimoo/hister)) `AGPL-3.0` `Go/Docker`
- [Manticore Search](https://github.com/manticoresoftware/manticoresearch/) - 小規模から大規模データまで高速に応答する全文検索・データ分析（Elasticsearch の代替）。 `GPL-3.0` `Docker/deb/C++/K8S`
- [MeiliSearch](https://www.meilisearch.com) - 関連性が非常に高く、即時かつタイプミスに強い全文検索 API。 ([ソースコード](https://github.com/meilisearch/MeiliSearch)) `MIT` `Rust/Docker/deb`
- [Meme Search](https://github.com/neonwatty/meme-search) - AI を活用したミーム検索エンジン。視覚言語モデルで画像から説明文を自動抽出し、ベクトル埋め込みでインデックス化してセマンティック検索とキーワード検索を実現。 ([ソースコード](https://github.com/meme-search/meme-search)) `Apache-2.0` `Docker`

### セルフホスティング基盤 / Self-hosting Solutions

- [DietPi](https://dietpi.com/) - シングルボードコンピューター向けに最適化された最小構成の Debian OS。自宅でのセルフホスティング用に複数のサービスを簡単にインストール・管理できる。 ([ソースコード](https://github.com/MichaIng/DietPi)) `GPL-2.0` `Shell`

- [Dropserver](https://dropserver.org) - 個人用 Web サービスのためのアプリケーションプラットフォーム。 ([ソースコード](https://github.com/teleclimber/Dropserver/)) `Apache-2.0` `Go/Deno`
- [FreedomBox](https://freedombox.org/) - プライベートな個人間通信のために、フリーソフトウェアで動く個人用サーバーを開発・設計・普及させるコミュニティプロジェクト。 ([ソースコード](https://salsa.debian.org/freedombox-team/freedombox)) `AGPL-3.0` `Python/deb`
