### 家系図 / Genealogy

**[`^ 目次に戻る ^`](../README.ja.md#目次)**

家系データを記録・整理・公開するための[家系図ソフトウェア](https://en.wikipedia.org/wiki/Genealogy_software)。

- [Genea.app](https://www.genea.app/) - 誰でも家系図を作成・編集できる、プライバシー重視の家系図ツール。データは GEDCOM 形式で保存され、処理はすべてブラウザ内で完結。 ([ソースコード](https://github.com/genea-app/genea-app)) `MIT` `Javascript`
- [Genealogy](https://genealogy.kreaweb.be/) - 家族とその関係を記録し、家系図を作成できる。 ([デモ](https://genealogy.kreaweb.be/), [ソースコード](https://github.com/MGeurts/genealogy)) `MIT` `PHP`
- [GeneWeb](https://github.com/geneweb/geneweb/wiki) - オフラインでも Web サービスとしても使える家系図ソフトウェア。 ([ソースコード](https://github.com/geneweb/geneweb)) `GPL-2.0` `OCaml`
- [Gramps Web](https://www.grampsweb.org/) - オープンソースの家系図デスクトップアプリ Gramps をベースにした、Gramps と相互運用可能な共同編集型の家系図 Web アプリ。 ([デモ](https://gramps-project.github.io/gramps-web-api/), [ソースコード](https://github.com/gramps-project/gramps-web-api)) `AGPL-3.0` `Docker`
- [webtrees](https://www.webtrees.net) - Web 上で代表的なオンライン共同編集型の家系図アプリケーション。 ([デモ](https://dev.webtrees.net/demo-stable/index.php?ctype=gedcom&ged=demo), [ソースコード](https://github.com/fisharebest/webtrees)) `GPL-3.0` `PHP`

### 生成 AI（GenAI） / Generative Artificial Intelligence (GenAI)

**[`^ 目次に戻る ^`](../README.ja.md#目次)**

[生成 AI（GenAI）](https://en.wikipedia.org/wiki/Generative_artificial_intelligence)は[人工知能](https://en.wikipedia.org/wiki/Artificial_intelligence)の一分野で、生成モデルを用いてテキスト、画像、動画などのデータを生成する。

- [Agenta](https://agenta.ai/) - プロンプト管理、LLM 評価、オブザーバビリティを備えた LLMOps プラットフォーム。共同でのプロンプトエンジニアリングにより、本番品質の LLM アプリケーションを構築・評価・監視できる。 ([ソースコード](https://github.com/agenta-ai/agenta)) `MIT` `Docker`
- [AnythingLLM](https://anythingllm.com/) - RAG、AI エージェント、ノーコードのエージェントビルダー、MCP 対応などを内蔵したオールインワンのデスクトップ／Docker 向け AI アプリケーション。 ([ソースコード](https://github.com/Mintplex-Labs/anything-llm)) `MIT` `Nodejs/Docker`
- [GoModel](https://gomodel.enterpilot.io/) - Go 製の AI ゲートウェイ。複数の LLM プロバイダーを OpenAI 互換の統一 API で扱え、USD 建てのコスト追跡、予算管理、利用状況分析、ガードレール、キャッシュ、管理ダッシュボードを備える。 ([ソースコード](https://github.com/ENTERPILOT/GoModel)) `MIT` `Go/Docker`
- [Khoj](https://khoj.dev/) - AI による「第二の脳」。Web や手元のドキュメントから回答を得られ、カスタムエージェントの作成、自動化のスケジュール、ディープリサーチも可能。オンライン／ローカルの任意の LLM を自律的なパーソナル AI として利用できる。 ([デモ](https://app.khoj.dev/), [ソースコード](https://github.com/khoj-ai/khoj)) `AGPL-3.0` `Python/Docker`
- [LibreChat](https://www.librechat.ai) `⚠` - 複数の AI プロバイダーに対応した、ChatGPT 互換の高機能 AI チャットインターフェース。マルチユーザー認証、メッセージ検索、プラグインに対応。 ([デモ](https://chat.librechat.ai), [ソースコード](https://github.com/LibreChat-AI/LibreChat)) `MIT` `Nodejs/Docker`
- [LLM Harbor](https://github.com/av/harbor) - コンテナ化された LLM ツールキット。LLM バックエンド、API、フロントエンド、各種追加サービスを簡潔な CLI で起動できる。 `Apache-2.0` `Docker/Shell`
- [LLMKube](https://llmkube.com) - セルフホスト LLM 推論のための Kubernetes オペレーター。差し替え可能なランタイム（llama.cpp、vLLM、TGI、Ollama、vllm-swift）、マルチ GPU シャーディング、NVIDIA CUDA と Apple Silicon Metal、OpenAI 互換 API に対応。 ([ソースコード](https://github.com/defilantech/LLMKube)) `Apache-2.0` `Go/Docker/K8S`
- [Local Deep Research](https://github.com/LearningCircuit/local-deep-research) - 複数ソース（arXiv、PubMed、Web）の検索、PDF のテキスト抽出、暗号化されたローカルストレージを備えた AI ディープリサーチツール。 `MIT` `Docker/Python`
- [LocalAI](https://localai.io/) - AI モデルをローカルで実行し、画像や音声も生成できる（OpenAI や Claude の代替）。 ([ソースコード](https://github.com/mudler/LocalAI), [クライアント](https://localai.io/gallery.html)) `MIT` `Docker/K8S`
- [Ollama](https://ollama.com/) - Llama 3.3、DeepSeek-R1、Phi-4、Gemma 3 などの大規模言語モデルを手軽に実行できる。 ([ソースコード](https://github.com/ollama/ollama)) `MIT` `Docker/Python`
- [Onyx Community Edition](https://onyx.app) - あらゆる LLM で使えるチャット UI。エージェント、Web 検索、RAG、MCP、ディープリサーチ、40 以上のナレッジソースへのコネクターなど高度な機能を搭載。 ([ソースコード](https://github.com/onyx-dot-app/onyx)) `MIT` `Docker/K8S`
- [Open-WebUI](https://openwebui.com) - 使いやすい AI インターフェース。Ollama と OpenAI API に対応。 ([ソースコード](https://github.com/open-webui/open-webui)) `BSD-3-Clause` `Docker/Python`
- [Vane](https://github.com/ItzCrazyKns/Vane) - AI 搭載の検索エンジン（Perplexity AI の代替）。 `MIT` `Docker`

### グループウェア / Groupware

**[`^ 目次に戻る ^`](../README.ja.md#目次)**

コラボレーションソフトウェア、または[グループウェア](https://en.wikipedia.org/wiki/Collaborative_software)は、共通の作業に取り組む人々が目標を達成できるよう支援するためのソフトウェア。ファイル共有、カレンダー・イベント管理、予約スケジューリング、アドレス帳など複数のサービスを、1 つの統合アプリケーションにまとめていることが多い。

_関連: [予約・スケジューリング](01.md#予約スケジューリング--booking-and-scheduling)_

- [Citadel](https://www.citadel.org/) - メール、カレンダー／スケジュール、アドレス帳、フォーラム、メーリングリスト、IM、Wiki・ブログエンジン、RSS 集約などを備えたグループウェア。 ([ソースコード](https://www.citadel.org/source.html)) `GPL-3.0` `C/Docker/Shell`
- [Colanode](https://colanode.com) - リアルタイムメッセージ、リッチテキストページ、ファイル管理、動的データベースを備えたコラボレーションスイート。オフラインでの作業を前提に設計（Slack、Notion の代替）。 ([ソースコード](https://github.com/colanode/colanode)) `Apache-2.0` `K8S/Docker`
- [Cozy Cloud](https://cozy.io/) - ファイル、メモ、連絡先、パスワード、ドキュメントを管理・同期できるパーソナルクラウド。 ([ソースコード](https://github.com/cozy/), [クライアント](https://github.com/cozy/cozy-store)) `GPL-3.0` `Nodejs`
- [Digipad](https://digipad.app/) - 共同編集できるデジタルメモパッドを作成するセルフホスト型オンラインアプリ（ドキュメントはフランス語）。 ([ソースコード](https://codeberg.org/ladigitale/digipad)) `AGPL-3.0` `Nodejs`
- [Digistorm](https://digistorm.app/) - 共同でアンケート、クイズ、ブレインストーミング、ワードクラウドを作成できる（ドキュメントはフランス語）。 ([デモ](https://digistorm.app/), [ソースコード](https://codeberg.org/ladigitale/digistorm)) `AGPL-3.0` `Nodejs`
- [Digiwall](https://digiwall.app/) - 対面・リモート作業向けのマルチメディア共同ウォールを作成できる（ドキュメントはフランス語）。 ([ソースコード](https://codeberg.org/ladigitale/digiwall)) `AGPL-3.0` `Nodejs`
- [egroupware](https://www.egroupware.org/) - カレンダー、アドレス帳、メモ帳、プロジェクト管理、顧客関係管理（CRM）、ナレッジ管理、Wiki、CMS を含むソフトウェアスイート。 ([ソースコード](https://github.com/EGroupware/egroupware)) `GPL-2.0` `PHP`
- [Group Office](https://www.group-office.com) - 企業向け CRM・グループウェア。プロジェクト、カレンダー、ファイル、メールを同僚や顧客とオンラインで共有できる。 ([ソースコード](https://github.com/Intermesh/groupoffice/)) `AGPL-3.0` `PHP`
- [Openmeetings](https://openmeetings.apache.org/index.html) - Red5 Streaming Server の API をリモーティングとストリーミングに利用した、ビデオ会議、インスタントメッセージ、ホワイトボード、ドキュメント共同編集などのグループウェアツール。 ([ソースコード](https://github.com/apache/openmeetings)) `Apache-2.0` `Java`
- [SOGo](https://www.sogo.nu/) - カレンダーやメッセージのデータに多様な方法でアクセスできる。CalDAV、CardDAV、GroupDAV、ActiveSync（Outlook のネイティブ互換を含む）、Web インターフェースに対応。 ([デモ](https://demo.sogo.nu/SOGo/), [ソースコード](https://github.com/Alinto/sogo)) `LGPL-2.1` `Objective-C`
- [Tine](https://www.tine-groupware.de/) - 企業や組織向けのデジタルコラボレーションソフトウェア。強力なグループウェア機能から便利なアドオンまでを備え、日々のチーム協業を容易にする。 ([ソースコード](https://github.com/tine-groupware/tine)) `AGPL-3.0` `Docker`
- [Tracim](https://github.com/tracim/tracim) - ファイル、スレッド、メモ、予定表などを備えたチーム協業プラットフォーム。 `AGPL-3.0/LGPL-3.0/MIT` `Python`
- [Zimbra Collaboration](https://www.zimbra.com/) - Web インターフェースと豊富な連携機能を備えたメール・カレンダー・コラボレーションサーバー。 ([ソースコード](https://github.com/zimbra)) `GPL-2.0/CPAL-1.0` `Java`

### 人事管理（HRM） / Human Resources Management (HRM)

**[`^ 目次に戻る ^`](../README.ja.md#目次)**

[人事管理システム](https://en.wikipedia.org/wiki/Human_resource_management_system)は、複数のシステムとプロセスを組み合わせ、[人的資源](https://en.wikipedia.org/wiki/Human_resources)、業務プロセス、データを容易に管理できるようにするもの。

- [admidio](https://www.admidio.org/) - 組織や団体の Web サイト向けユーザー管理システム。柔軟なロールモデルにより、組織の構造や権限をそのまま反映できる。 ([デモ](https://www.admidio.org/demo/), [ソースコード](https://github.com/Admidio/admidio)) `GPL-2.0` `PHP/Docker`
- [Frappe HR](https://frappe.io/hr) - 従業員管理、オンボーディング、休暇から給与計算、税務まで、13 以上のモジュールを備えた包括的な HRMS ソリューション。 ([ソースコード](https://github.com/frappe/hrms)) `GPL-3.0` `Docker/Python/Nodejs`
- [MintHCM](https://minthcm.org/) - 有名な業務アプリ SugarCRM Community Edition と SuiteCRM をベースにした人的資本管理ツール。 ([ソースコード](https://github.com/minthcm/minthcm)) `AGPL-3.0` `PHP`

### IoT（モノのインターネット） / Internet of Things (IoT)

**[`^ 目次に戻る ^`](../README.ja.md#目次)**

[モノのインターネット](https://en.wikipedia.org/wiki/Internet_of_things)とは、センサー、処理能力、ソフトウェアなどの技術を備え、インターネットを介して他の機器と接続・データ交換する物理的なモノのこと。

- [evcc](https://evcc.io/) - 拡張可能な電気自動車（EV）充電コントローラー兼家庭用エネルギー管理システム。 ([ソースコード](https://github.com/evcc-io/evcc)) `MIT` `deb/Docker/Go`
- [FHEM](https://fhem.de/fhem.html) - 照明や暖房の切り替えなど、家庭の定型作業を自動化。温度や消費電力などのイベント記録にも使える。Web やスマートフォンのフロントエンド、telnet、TCP/IP で直接操作可能。 ([ソースコード](https://svn.fhem.de/trac)) `GPL-3.0` `Perl`
- [FlowForge](https://flowforge.com/) - Node-RED アプリケーションを信頼性・スケーラビリティ・セキュリティを確保してデプロイできる。Node-RED 開発チーム向けに DevOps 機能を提供するプラットフォーム。 ([ソースコード](https://github.com/FlowFuse/flowfuse)) `Apache-2.0` `Nodejs/Docker/K8S`

- [Home Assistant](https://home-assistant.io/) - ホームオートメーションプラットフォーム。 ([デモ](https://home-assistant.io/demo/), [ソースコード](https://github.com/home-assistant/core)) `Apache-2.0` `Python/Docker`
